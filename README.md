# Flappy Bird

A 2D arcade-style game developed in Unity and C#, inspired by the classic Flappy Bird gameplay experience. The game features responsive player controls, procedurally generated obstacles, collision detection, score tracking, and game-state management.

## Overview

Flappy Bird is a fast-paced 2D arcade game where the player controls a bird and navigates it through a series of obstacles. The objective is to achieve the highest possible score while avoiding collisions.

The project demonstrates the implementation of core gameplay systems in Unity, including player movement, physics-based interactions, obstacle management, collision handling, scoring, and game-state control.

## Features

- Responsive bird movement and controls
- Physics-based player movement
- Continuously generated pipe obstacles
- Collision detection and game-over handling
- Real-time score tracking
- Increasing gameplay challenge
- Restart functionality
- 2D game environment and UI
- Audio and visual feedback
- Clean and modular C# scripts

## Gameplay

The player controls the bird by making it fly upward while gravity continuously pulls it downward. The goal is to navigate through the gaps between the pipes without colliding with them.

Each successfully passed obstacle increases the player's score. The game ends when the bird collides with an obstacle or the environment.
